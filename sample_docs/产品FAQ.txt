智能客服产品 FAQ

Q1：产品支持哪些接入方式？
A1：支持三种：网页 JS 嵌入、微信公众号/小程序 SDK、以及 HTTP API 对接。

Q2：知识库支持哪些文档格式？
A2：支持 PDF、Word（docx）、纯文本（txt）。扫描件需要先做 OCR 识别。

Q3：一次最多能上传多大的文档？
A3：单个文档不超过 10MB，单次批量上传不超过 50 个文件。

Q4：问答响应大概多久？
A4：平均 1-3 秒（含检索与生成）；长文档首次入库需要额外时间做向量化。

Q5：如何保证回答不编造内容？
A5：系统只根据知识库中检索到的内容作答，检索不到时直接回复"未收录"，并在回答下方标注来源文档。
